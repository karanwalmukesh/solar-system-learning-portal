# 🌟 Solar System Learning Portal

An interactive 3D solar system learning portal for Grade 3 children. Explore planets, complete missions, earn badges, and become a space explorer!

## 🚀 Features

- **3D Solar System** - Interactive 3D planets with smooth animations
- **Spaceship Travel** - Fly your spaceship to any planet
- **Educational Narration** - 3 educational facts + 1 fun fact per planet
- **Mission System** - Complete challenges to earn stars and badges
- **Badge Collection** - Earn 12+ badges for achievements
- **Quiz System** - Test your knowledge about planets
- **Progress Dashboard** - Track your learning journey
- **Supabase Backend** - Save progress, badges, and scores

## 🛸 Tech Stack

- React 18
- Three.js / React Three Fiber
- TailwindCSS
- Supabase
- Framer Motion
- Recharts
